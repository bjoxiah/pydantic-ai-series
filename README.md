> Part of the **[Master Pydantic AI Series](https://github.com/bjoxiah/pydantic-ai-series)** — a hands-on series on building production AI agents with Pydantic AI.

This lesson shows how to evaluate a Pydantic AI agent's responses with `pydantic-evals` — `Case`, `Dataset`, and `LLMJudge` — using an agent and rubric as a worked example.
